### Project Status

The complexities of a game engine cannot be understated.  Navigating the Unity software and 3D space within the project is a massive learning curve.  The majority of my work on this project so far has been focused on the fundamental use of Unity.  A core goal of this project was to learn how to use Unity and I have made progress.  Some of the functions that I’ve gained experience with so far are:

- Project Navigation: Script creation tools, hierarchy view and inspector tools.
- Scene navigation: Moving within the 3D space.
- Asset management: Utilizing prefabricated assets within a scene.  The boat that I am using as a ride vehicle is a great example of this. 
- Unity Spline Package: The spline package was used to create the ride path.  The spline animate tool was used to move the boat along the path. 
- Game Object Processes: This includes scaling the size of game assets, positioning, rotation, and main camera management.  Two features specific to my project are utilizing a material (water) within a game object and utilizing a custom mesh to limit the water to the ride path within that game object.

I have also written a custom mesh in C# for the ride path.  The script samples points along a spline, finds edges based on the width of the mesh, and generates a series of triangles within the mesh.  The mesh and a water material asset are applied to an empty game object.  The final result resembles a water flume that the boat can travel along.  Some of the computer science fundamentals that I’ve utilized so far are:

- Data Structures: Lists and Vectors.
- Conditional Statements.
- For Loops.
- Unity API.

### Expected Changes

I am planning to utilize basic visuals and plan to focus more on the exploration of C#.  I plan to focus on the implementation of the following:

- Show control: boat movement (moving, paused at a scene, etc.), effects control, animation triggers, etc.

If time allows, I plan to polish the visual appeal and flow of the ride.

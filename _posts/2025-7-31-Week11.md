### Weekly Accomplishments

This week's focus was on blocking, material assignment, and planning the next additions to this project with an emphasis on programming tasks.  I laid in a few platforms that would represent scene locations, assigned a material the mesh that was developed last week for the ride path's railing, and have a good grasp on the additions to the project that I would like to make before the semester's end.

### This week's goals

- Develop a ride state machine: This will be basic zone representation that tracks the state of the ride vehicle as it travels along the ride path.  Some examples are: waiting, loading, safety check, departing station, in motion, mid show, and returning.
- Sketch timeline control mechanism: This feature would detect the boat's proximity to a scene and trigger certain features of each scene along the ride path.
- Sketch Emergency Stop system: This feature would handle events that require the ride to stop and control the guest experience with things like ride announcements and emergency lighting.

### Current Challenges

I continue to struggle between a focus on ride control and the visual appeal that I envisioned when I started this project.  Ride control mechanisms are what I've chosen to focus on for the remainder of the semester.  I'm still swimming in an endless sea of Unity API functions that are necessary for the successful C# implementation of the features that I've chosen to develop.

### Reflections

Starting from scratch is hard.  Learning is hard.  That said, this is all extremely rewarding and I look forward to a career path that requires life long learning and adaptation.

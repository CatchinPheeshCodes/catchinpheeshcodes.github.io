### Weekly Accomplishments

This week's primary accomplishment was another custom mesh written in C#.  This script will render 'rails' or barriers that resemble what you would see in a flume for a themed boat ride.  This program is similar to the mesh that was created to render a waterway that follows the spline that represents the boat path.  Key elements were duplicated for the barriers to the left and right side of the flume, and the geometry now includes a height variable.  

### This week's goals:

- Assign a material for the rail mesh to extrude.
- Lay in some basic visual elements along the boat path.
- Identify key functions that require a focus on coding and fundamentals.

### Current Challenges

The challenges for this project have been steady throughout the semester, and remain so.  Learning new languages and complex software environments is very time consuming.  My goals have shifted a bit.  I would be happy with a solid foundation of key elements that contribute to a simulated experience, primed for future enhancements.

### Reflections

The amout of work that goes into creating visual media with software is astounding.  My only prior exposure to this kind of work has been with a project called 'Raytracer in a Weekend'.  The outcome of that project was quite astonishing in the end, but it was more of a tutorial that taught the math involved in ray tracing.  With both of these projects, I have become more comfortable with C like languages.  Although there are clear differences between C++ and C#, this project has been an excellent refresher in C like languages.  This should be a great foundation, heading into the programming intensive elective next fall that will be taught in C++.

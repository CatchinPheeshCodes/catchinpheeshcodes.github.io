### Weekly Accomplishments

Finally getting to some code!  This week's primary accomplishment was the creation of a custom mesh for the ride track.  The script samples points along the spline that I created last week with Unity's spline package and renders the water material within a set width between the edges of the mesh.  This video was instrumental in understanding what a mesh is in Unity: [A Coder's Guide to Spline Based Procedural Geometry](https://www.youtube.com/watch?v=o9RK6O2kOKo).  The video actually shows how to create a mesh that uses Bezier splines to create things like tracks and roads in Unity.  I've mentioned before the idea of using a Catmull-Rom spline instead of Unity's Spline package.  The curves are much smoother with a custom script and the geometry is very impressive.  My current boat path can be choppy at times, so this is certainly an opportunity for improvement.
